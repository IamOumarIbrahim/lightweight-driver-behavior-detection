# Windows Launchers

Run [`setup`](setup/) first, then [`data`](data/) preparation, then a
track-specific [`RGB`](RGB/) or [`NIR`](NIR/) launcher. Every training and
protected-test `.bat` requires typed confirmation. [`publication`](publication/)
builds paper figures from frozen results with R and ggplot2 and compiles the IEEE
manuscript. Implementation lives under [`tools`](../tools/).
