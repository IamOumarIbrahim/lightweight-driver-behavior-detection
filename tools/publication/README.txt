PUBLICATION TOOLS
figures.R uses pinned R and ggplot2 to convert frozen aggregate JSON into IEEE-sized PDF, SVG, and 600-DPI PNG figures. R-runtime.lock.json and R-packages.lock.csv freeze the complete local figure environment. pdf_metadata.py normalizes only Cairo PDF metadata for stable hashes; all graphical content is generated by ggplot2. The generator never reads checkpoints or active training directories.

export_rgb_predictions.py copies only predictions and validation-selected operating metadata from the six frozen local RGB YOLO test results into results. It rejects metric mismatches and strips local paths. analyze_rgb.py reproduces structural annotation checks plus macro, class, subject, and paired-seed metrics from those public predictions. Neither utility loads a model or performs inference.
