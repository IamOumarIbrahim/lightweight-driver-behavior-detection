# Publication Tools

`figures.R` uses pinned R and ggplot2 to convert frozen publication sources into
IEEE-sized PDF and SVG figures plus 600-DPI PNG previews. Explicitly
status-tagged partial sources are supported while runs are active.
`R-runtime.lock.json` and `R-packages.lock.csv` freeze the complete local figure
environment. `pdf_metadata.py` normalizes only Cairo PDF metadata for stable
hashes; all graphical content is generated by ggplot2. The generator never
reads checkpoints or active training directories. Pass
`--only-protocol-workflow` to rebuild only the shared protocol figure and its
manifest when a protocol-only documentation change does not affect other plots.

`export_rgb_predictions.py` copies only predictions and validation-selected
operating metadata from the six frozen local RGB YOLO test results into
`results`. It rejects metric mismatches and strips local paths. `analyze_rgb.py`
reproduces structural annotation checks plus macro, class, subject, and paired-
seed metrics from those public predictions. `analyze_rgb_validation.py`
converts the six frozen validation outputs into a public threshold sweep without
publishing local paths. None of these utilities loads a model or performs
inference.

`analyze_nir.py` verifies the identity, hashes, CUDA profile, and paired-ratio
completeness of every available NIR protected result, then writes the path-safe
partial or complete source consumed by the NIR figure. It never reads local
checkpoints, predictions, or protected annotations.
