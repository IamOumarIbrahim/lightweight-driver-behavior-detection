# Data

## Placement

Put the licensed DMD folder in `data/DMD` and Drive&Act in `data/Drive&Act`.
These media folders and `data/processed` are local-only and ignored by Git.

## Published Data

[`data/annotations`](annotations/) contains portable authored annotations and
frozen split metadata. Run the launchers in [`scripts/data`](../scripts/data/)
in numeric order to unpack sources, derive frames, and verify integrity.

## Licenses

DMD and Drive&Act remain subject to their original licenses and access terms.
This repository publishes annotations and split metadata, not source frames or
videos.
